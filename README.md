# 💖 Романтичний сюрприз для Анастасії

Інтерактивний веб-сайт у стилі пошукової системи з автоматичною анімацією, фотогалереєю та зворушливим фінальним повідомленням.

---

## ✨ Як працює сценарій (8–12 секунд)

1. **Сканування QR-коду** — відкривається чиста, мінімалістична сторінка, візуально натхненна класичним інтерфейсом пошуковика.
2. **Автоматичний набір тексту** — у пошуковому рядку плавно друкується слово: **«богиня»** (100–140 мс на символ).
3. **Пауза та «клік»** — пауза 700 мс, кнопка «Пошук» імітує натискання.
4. **Кінематографічний перехід** — верхній прогрес-бар (Google-style) імітує реальний пошуковий запит (~950 мс).
5. **Результати пошуку** — відкривається сторінка з тлумачним словником слова *«богиня»* («Див. фотографічні докази нижче»).
6. **Послідовна поява фотографій** — фотографії Анастасії з'являються одна за одною з м'якою анімацією ковзання вгору.
7. **Фінальне романтичне послання**:
   > *Схоже, Google знає відповідь ❤️*  
   > **Богиня — це ти.**
8. **Кнопка «Ще раз»** — дозволяє перезапустити всю магію з самого початку.

## 📸 Як додати реальні фотографії Анастасії

### Спосіб 1: Заміна файлів у папці проекту (найкраще для деплою)
Просто скопіюйте 6 фотографій у папку `public/photos/` з такими назвами:
- `public/photos/photo1.jpg`
- `public/photos/photo2.jpg`
- `public/photos/photo3.jpg`
- `public/photos/photo4.jpg`
- `public/photos/photo5.jpg`
- `public/photos/photo6.jpg`

*(Підтримуються також формати `.png`, `.webp`, `.jpeg` — просто вкажіть відповідні шляхи у файлі `src/data/photos.ts`)*

### Спосіб 2: Редагування підписів та тегів
Відкрийте файл `src/data/photos.ts` і змініть текст підписів під кожним фото на власні спогади чи компліменти:
```typescript
{
  id: 'photo-1',
  url: '/photos/photo1.jpg',
  caption: 'Та сама неперевершена усмішка',
  tag: 'Портрет дня',
}
```

### Спосіб 3: Миттєве завантаження через інтерфейс (для тесту)
На сторінці результатів пошуку натисніть на іконку камери у правому верхньому кутку (або знизу на смартфоні) — відкриється вікно завантаження фотографій, де можна вибрати фотографії з вашого пристрою без перезапуску коду.

## 🚀 Запуск проекту локально

```bash
# Встановлення залежностей (вже виконано)
npm install

# Запуск сервера розробки
npm run dev

# Збірка для продакшену
npm run build
```

---

## 📱 Як відкрити на смартфоні через QR-код

1. Запустіть локальний сервер з параметром `--host`:
   ```bash
   npm run dev -- --host
   ```
2. У терміналі відобразиться локальна IP-адреса вашої мережі (наприклад: `http://192.168.1.15:5173`).
3. Переконайтеся, що комп'ютер і телефон підключені до одного Wi-Fi.
4. Згенеруйте QR-код для цієї адреси або задеплойте сайт на **Lovable**, **Vercel** або **Netlify**, щоб отримати постійне посилання, і роздрукуйте чи надішліть гарний QR-код!
